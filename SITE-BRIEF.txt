0. EK LINE MEIN
   Ek hi banda (owner) ke SSC CGL Tier-1 ki tayari ka poora system: PYQ bank,
   notes, current affairs, vocab, mock marks, galtiyon ki notebook, aur 18-din
   ka mission plan — sab ek site par, sab offline-first, aur PC wale overlay
   (D:\over) se juda hua.

   data localStorage + IndexedDB mein, do device ke beech Supabase se sync.

6. PC OVERLAY (D:\over) SE JUDAAV — site ka doosra aadha hissa
================================================================================

Overlay ek Tk window hai jo hamesha upar rehta hai + apna Flask server
(127.0.0.1:5000-5002). Site usse localhost par baat karti hai.

  OverlayInbox   overlay se aaye screenshot question site ke wrong book mein
  VocabFeeder    (a) overlay ko vocab ke words deta hai, (b) copy hui meaning
                 leta hai (New Words), (c) 📝 one-liner leke /oneliners mein
  /ai-run        overlay ka 🤖 Run — question ek-ek karke AI se, jawab save
  Overlay ke page: /q/<qid> (ek question + baayen numbers ki list + 🎯 20 similar),
                 aur 📚 Padho (panel ke button se) — Fact log, Zaroori baatein,
                 One-liners, Current Affairs aur PYQ bank ek hi page par,
                 "Agla" dabao -> hara nishan + 50 card baad phir se, upar
                 "kitne hare / kitne baaki", aur 🐋 DeepSeek ka apna button.

NIYAM (kabhi mat todna):
  • Gemini API kabhi use nahi hoti (paise lagte hain). Gemini sirf wahi chalta
    hai jo user khud browser mein kholta hai (✨ button clipboard par prompt
    daal kar page khol deta hai).
  • DeepSeek user ki apni key se — automatic/bulk call nahi, sirf button par.
  • OCR muft wala local (RapidOCR / Windows OCR), overlay mein.
