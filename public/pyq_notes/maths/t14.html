Algebra: shuru se, aur bina lambi expansion ke 36-second wale tareeke

2025–26 SSC PYQs (CGL, CHSL, CPO, SP-XIV, MTS, Delhi Police, GD 2026) · sabse zyada: x + 1/x, "a + b aur ab diya", surd x = a + √b, teen number wali identity

Pehle ek chhoti si kahani: do number, teen sawaal

Maan lo do number hain, 5 aur 2. Inke baare mein teen cheezein bata sakte ho:

  • Jod: 5 + 2 = 7
  • Guna: 5 × 2 = 10
  • Farq: 5 − 2 = 3

Ab koi poochhe "dono ke square ka jod?" Toh 25 + 4 = 29. Par agar sirf "jod 7 aur guna 10" bataya ho, aur number na bataye hon? Tab bhi 29 nikal aata hai: 7 × 7 = 49, usmein se 2 × 10 = 20 hatao. 49 − 20 = 29.

Bas yahi algebra hai. Number chhupa diye, unki jagah a aur b likh diya. Par jod, guna, farq ka rishta wahi rehta hai. Isi rishte ko identity kehte hain.

Ab naam rakh dete hain Identity = aisa barabar ka nishaan jo har number par sach ho. (a + b)² = a² + 2ab + b² ko 5 aur 2 daal kar check karo: 49 = 25 + 20 + 4. Sach.
Equation = sirf kuch numbers par sach. x + 3 = 5 sirf x = 2 par sach hai.
Is chapter ke 90% sawaal identity wale hain. Equation wale bahut kam hain, aur unmein bhi options daal kar dekhna sabse tez hai.

3 badi baatein (poora chapter inhi se chalta hai)

  • 1. Identity har number par sach hai, toh apna number "maan lo". Options mein x, y, a, b wale expression hain? Apna chhota number daalo (1, 0, 2) aur dekho kaunsa option wahi number deta hai. Koi expansion nahi.
  • 2. Do number ki duniya sirf jod (s), guna (p), farq (d) hai. Inmein se koi do pata hon, teesra aur baaki sab nikal aata hai.
  • 3. x + 1/x bhi wahi do-number wali kahani hai. Do number x aur 1/x, jinka guna hamesha 1 hai. Isliye x + 1/x ke sawaal sabse aasaan hain: guna pehle se pata hai.
Formula / value sheet to memorise (sirf yahi chahiye) Do number (s = a + b, p = ab, d = a − b):
a² + b² = s² − 2p = d² + 2p · d² = s² − 4p · a² − b² = s × d
a³ + b³ = s³ − 3ps · a³ − b³ = d³ + 3pd · a⁴ + a²b² + b⁴ = (a² + b²)² − p²
Teen number (S = a + b + c, Q = ab + bc + ca):
a² + b² + c² = S² − 2Q · a³ + b³ + c³ − 3abc = S × (a² + b² + c² − Q)
a + b + c = 0 ho toh a³ + b³ + c³ = 3abc · (a − b)² + (b − c)² + (c − a)² = 2(a² + b² + c² − Q)
Cube khol ke: (a + b)³ = a³ + 3a²b + 3ab² + b³ (1-3-3-1) · a³ + b³ = (a + b)(a² − ab + b²) · a³ − b³ = (a − b)(a² + ab + b²)
x + 1/x = k: x² + 1/x² = k² − 2 · x³ + 1/x³ = k³ − 3k · x − 1/x = d: x² + 1/x² = d² + 2 · x³ − 1/x³ = d³ + 3d
CGL+ x positive ho toh x + 1/x ≥ 2 (sabse kam 2, jab x = 1) · a² + b² + c² − ab − bc − ca = ½[(a − b)² + (b − c)² + (c − a)²]
Squares 11–30 aur cubes 1–15 zubaani: 13² = 169, 17² = 289, 24² = 576, 27² = 729 · 11³ = 1331, 12³ = 1728.

Paper mein ek sawaal ko lagbhag 36 second milte hain. Neeche 8 tareeke hain. Har ek ke saath likha hai kab lagana hai aur kitna time leta hai.

Speed method 1 · Value maan lo (sabse bada hathiyar)

Kab use karo: jab options mein x, y, a, b wale expression hon ("simplify karo", "expand karo", "kis ke barabar hai"). Ya jab sawaal mein x + 1/x = 2 ya −2 ho.

Soch aise: identity har number par sach hai. Toh sabse aasaan number daalo. Sawaal ek number ban jayega, har option bhi ek number ban jayega. Jo match kare, wahi answer.

  • Pehle 1 aur 0 try karo. Agar do option same number dein, toh 2 daal ke dobara dekho.
  • x + 1/x = 2 → seedha x = 1. x + 1/x = −2 → x = −1. Ab koi bhi power: 1 ya ±1.
  • a + b + c = 0 wale sawaal: a = 1, b = −1, c = 0 maan lo (ya 1, 1, −2).
  • Homogeneous fraction (upar neeche sab terms ki same degree) mein decimals hon: sabko 100 se guna kar do, ratio wahi rahega.
Demo · (x + y)³ − (x − y)³ = ? · ~10 sec x = 1, y = 1 maan lo: 2³ − 0³ = 8.
Options: 6xy(x − y) = 0 ✘ · 2y(3x² + y²) = 2 × 4 = 8 ✔ · 2y(3x² − y²) = 4 ✘ · 2y(x² + y²) = 4 ✘.
Demo · x + 1/x = −2. x⁶ + 1/x⁶ − 3(x⁴ + 1/x⁴) + 4(x² + 1/x²) = ? · ~8 sec x = −1. Har even power = 1, toh har (xⁿ + 1/xⁿ) = 2.
2 − 3 × 2 + 4 × 2 = 2 − 6 + 8 = 4.
Trick: "Option mein letter, toh tum daalo number." Maan-lo wale number aise chuno ki koi option zero ya barabar na ban jaye. x = y = 1 se (x − y) wale sab zero ho jaate hain, wahan x = 2, y = 1 lo.

Speed method 3 · Do number: s, p, d ka triangle (aur "number hi nikaal lo")

Kab use karo: a + b, ab, a − b, a² + b² mein se do diye hon, aur koi aur maanga ho.

"Number hi nikaal lo" wala tareeka: SSC aksar chhote number rakhta hai. Jod 7, guna 12 → 4 aur 3. Jod 11, farq 5 → 8 aur 3. Ek baar number mil gaye toh a⁴ − b⁴ bhi seedha 4096 − 81.

Speed method 5 · Surd ka jodi-dar (conjugate)

Kab use karo: x = 2 + √3, a = √7 + √5, y = 3 − √8 jaise sawaal.

  • Jodi-dar: 2 + √3 ka jodi-dar 2 − √3. Dono ka guna = 4 − 3 = 1. Toh 1/x = 2 − √3, aur x + 1/x = 4.
  • Guna 1 tabhi aata hai jab (pehla)² − (doosra)² = 1. 3 − √8: 9 − 8 = 1 ✔. 5 + 2√6: 25 − 24 = 1 ✔.
  • a = p + √q, b = p − √q → a + b = 2p, ab = p² − q, aur a² + b² = 2(p² + q). Seedha!
  • x = √5 + 2 diya, x² − 4√5 maanga? x² = 5 + 4 + 4√5 = 9 + 4√5. √ wala hissa kat gaya, bacha 9.
Demo · a = 4 + √7, b = 4 − √7. a² + b² = ? · ~5 sec 2 × (16 + 7) = 2 × 23 = 46. Bas.

Speed method 6 · Componendo-Dividendo (jod/farq ka ulta)

Kab use karo: (√(5 + x) + √(5 − x)) ÷ (√(5 + x) − √(5 − x)) = 3 jaisa fraction, jismein upar jod aur neeche farq ho.

Soch aise: (A + B)/(A − B) = 3 ho toh A : B = (3 + 1) : (3 − 1) = 4 : 2 = 2 : 1. Kyunki agar A = 2, B = 1, toh (2 + 1)/(2 − 1) = 3 ✔.

Demo · (√(5 + x) + √(5 − x)) / (√(5 + x) − √(5 − x)) = 3. x? · ~12 sec √(5 + x) : √(5 − x) = 4 : 2 = 2 : 1. Square karo: (5 + x) : (5 − x) = 4 : 1.
5 + x = 4(5 − x) → 5x = 15 → x = 3. (Ya option daalo: x = 3 → √8 aur √2, yaani 2√2 aur √2 → 3√2/√2 = 3 ✔.)

Speed method 7 · Options daal ke dekho (equation wale sawaal)

Kab use karo: "x ki value kya hai", "number kaunsa hai", "kaunsa pair" wale sawaal. Hal karne se tez hai option daalna.

  • √(x + 3) + √(x − 2) = 5: x = 6 → 3 + 2 = 5 ✔. Ek line.
  • "Square mein se do guna number ghatao, 80 aata hai": 10 → 100 − 20 = 80 ✔.
  • Options mein se pehle wo daalo jo √ ko poora square banaye (x + 3 = 9, x − 2 = 4).

Speed method 8 · Unit digit aur bade number

  • 14² + 87² kis ke barabar? Sirf aakhri digit: 6 + 9 = 15 → 5. Jis option ka aakhri digit 5 ho, wahi. (41² + 78²: 1 + 4 = 5 ✔.)
  • Bade number dekho toh identity pehchano: 51 × 49 = (50 + 1)(50 − 1) = 2500 − 1. (785³ + 215³)/(785² − 785 × 215 + 215²) = 785 + 215 = 1000.
  • 14² + 16² + 24² + 2(14 × 16 + 16 × 24 + 24 × 14) = (14 + 16 + 24)² = 54² = 2916.
