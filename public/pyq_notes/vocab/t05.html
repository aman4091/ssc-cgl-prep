Hopeful; Optimism.

Eulogize; Extol.

Esteem. Disrepute, stigma and infamy are synonyms.

Arrogant. Servile = slavishly obedient.

Refined (fully developed). Inchoate = just begun, unformed.

Loquacious; Succinctness.

Harsh. Dulcet = sweet-sounding.

⚠ Answer-key notes Warned → Imperiled: warning protects someone from danger; "imperiled" means putting someone in danger. Not a dictionary pair, but the other options (predicted, prepared) are near-synonyms. Accept as per key.
Acclimatise → Disarrange: acclimatise = adjust/settle; key takes "disarrange" (unsettle). Weak but the only workable option.
Raciness → Perfection: raciness = lewdness; the other three options are synonyms, so the key is the odd one out. Read it as "indecency ↔ propriety".
Elusive → Affordable: elusive = hard to get; key reads "affordable" as "easily obtained". "Definite" (for elusive = hard to define) was also arguable. Accept as per key.
Trick: Jab teen options synonym hon (Lewdness, Obscenity, Filth) aur ek bilkul alag (Perfection) — alag wala hi antonym ka key hota hai. Ye "odd one out" rule bahut sawaal bachaata hai.
