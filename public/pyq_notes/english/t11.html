Error Pro bank, 170 questions · this part: superlative ↔ comparative ↔ positive, "not so … as", only → none but, must → cannot but, as soon as → no sooner … than
How to read this rule book In transformation you rewrite a sentence in a new form, and the meaning and the tense must not change. Every rule has one plain line, one fresh example and a table built from the bank (Q = question number). The ✗ column shows the most tempting wrong option with the faulty part highlighted; the ✓ column is the key. Q ×6 = how many bank questions test the rule. CGL+ = standard SSC point not in this bank.
Trick: First kill the options that change the tense (went → goes, built → has built) or the meaning (one of the best → the best). Usually only one option is left.

The three degrees side by side

An adjective has three degrees. Positive = the plain form (tall, beautiful). Comparative = the -er / more form (taller, more beautiful). Superlative = the -est / most form (tallest, most beautiful).

Rule 1 · Superlative ↔ Positive: "No other … as … as" Q ×3

Rule: "X is the most / -est" becomes "No other … is as + adjective + as X", and back again.

✗ Ravi is the tallest boy. → Ravi is as tall as any boy. → ✓ No other boy in the class is as tall as Ravi.

Transformation (2): Interrogative and Exclamatory ↔ Assertive

Most tested: positive question → negative statement, "Who / anyone" → no one / everyone, What / How → very, Hurrah / Alas → "It is a matter of …", If only → I wish
Three words first Assertive = an ordinary statement ending in a full stop. Interrogative = a question. Exclamatory = a sentence that shows strong feeling and ends in "!". In a "rhetorical" question the speaker does not want an answer; the question is a strong statement in disguise. Converting it means writing that hidden statement.

Transformation (3): Simple ↔ Compound ↔ Complex

Most tested: participle openers (Being…, Having…), cause, contrast (despite ↔ though ↔ but), condition (without ↔ if … not ↔ or), too … to ↔ so … that, who / which clauses
Four terms in one line each Finite verb = a verb that shows tense and has its own subject (is, went, has finished). Clause = a subject + a finite verb. Simple sentence = one finite verb; extra ideas sit in phrases (to + V1, V-ing, despite, because of). Compound = two equal clauses joined by a coordinating conjunction (FANBOYS: for, and, nor, but, or, yet, so). Complex = one main clause + one clause that depends on it, joined by a subordinating word (when, because, though, if, unless, so that, who, which…).

Which type is it?

One meaning, three dresses

Trick: Eliminate by type first. Asked for simple? Throw out every option with and / but / so / because / when. Asked for compound? Throw out because / since / although / while / when. Asked for complex? Throw out and / but / so. Then check tense.

Rule 15 · Participle opener (V-ing / Being / Having + V3) ↔ When / As / Since clause ↔ and / so Q ×16

Rule: a participle is a verb form used like an adjective (Hearing, Being tired, Having finished). It shares the subject of the main clause. Simple → complex: "When / As / Since + subject + verb". Simple → compound: "… and / so …". Going back, drop the subject and the conjunction and use the -ing form.

✗ Reaching home, the rain started. (the rain did not reach home) → ✓ Reaching home, I saw that the rain had started.

Most tested: personification, simile vs metaphor, hyperbole, euphemism, onomatopoeia · also oxymoron, alliteration, pun, irony
