How to read this rule book Every rule has one plain line, one fresh example, and a table built from the bank (the Q column is the question number in the tense bank). Highlighted = the wrong part. Q ×8 = how many bank questions test the rule. CGL+ = standard SSC rule or example not in this bank.

The 12 tenses on one timeline

A tense is the verb form that tells when an action happens. There are 3 times (past, present, future) and 4 "shapes" for each: indefinite (a plain fact or one action), continuous (going on), perfect (finished before a point) and perfect continuous (going on for some time up to a point). 3 × 4 = 12.

Rule 1 · Facts, definitions and habits → simple present Q ×14

Rule: a general truth, a definition, a regular habit or "what always happens" takes V1 / V1+s (negative: don't / doesn't + V1), not the past and not "will".

✗ Water boiled at 100 °C. → ✓ Water boils at 100 °C.

Rule 2 · Right now, these days, "always" complaints → present continuous Q ×8

Rule: an action going on at this moment, or a temporary trend (these days, nowadays), takes am / is / are + V-ing. "Always" + continuous shows an annoying habit.

✗ Look! The baby sleeps. → ✓ Look! The baby is sleeping.

Rule 3 · State verbs do not take -ing Q ×2

Rule: verbs that show a state, not an action (have = own, know, like, love, want, believe, understand, seem, belong, see, hear) are normally not used in the continuous form.

✗ I am knowing him well. → ✓ I know him well.

Q✗ Wrong✓ Right
50Are you having your own transport to go home?Do you have your own transport…? (have = own)

CGL+ The same verb can be an action: "She is having lunch" (= eating) ✓, "We are having a party next week" (= organising) ✓, "I am seeing the doctor today" (= meeting) ✓. Q16 and Q91 use "having" this way. Also see Q71 (Rule 16): "was knowing" → had known.

Rule 4 · Present perfect: past action, result now Q ×16

Rule: use has / have + V3 when the time is not finished or not named and the result matters now: just, already, yet, ever, never, before, so far, till date, "the first time", "now" after a past story, "over the past year".

✗ I finished my work, so I can play now. (acceptable in US English) → ✓ I have finished my work, so I can play now.

Rule 5 · Since = point of time, for = length of time Q ×5

Rule: "since" is followed by a starting point (since Monday, since 2019, since last winter); "for" is followed by a length (for two hours, for six months, for the last three weeks).

✗ I have lived here since ten years. → ✓ I have lived here for ten years.

Rule 6 · For / since / how long + still going on → has been + V-ing Q ×10

Rule 7 · The future: will, going to, or present continuous Q ×8

Rule: use will + V1 for a decision now or a plain future; "be going to" when present signs show it is coming; present continuous for a fixed plan. A future time word (next week, this coming Monday) never takes a past form.

✗ Look at those clouds! It rains. → ✓ It is going to rain.

Rule 8 · No "will" after when / before / until / by the time / as soon as Q ×5

Rule: in a time clause about the future, use the simple present; keep "will" only in the main clause. Two "will"s in one sentence about one time is wrong.

✗ I will call you when I will reach. → ✓ I will call you when I reach.

Rule 9 · By the time / by then (future) → will have + V3 Q ×3

Rule: if an action will be finished before a future point, it takes will have + V3; the clause that names the point (by the time…) stays simple present.

✗ By next March, I will finish the course. → ✓ By next March, I will have finished the course.

Rule 10 · Timetables take the simple present CGL+

Rule: a fixed, official schedule (trains, flights, exams, films) uses the simple present even for the future.

✓ The train leaves at 6:15 tomorrow. · ✓ The exam starts next Monday. Q60 shows the limit: a bus that is "full and about to go" is not a timetable, so "is going to leave" fits better.

Check yourself

"She ___ in Delhi since 2018." lives / has been living?

has been living. "Since + point" and still going on (Rule 6).

"I haven't seen him ___ three weeks." since or for?

for. "Three weeks" is a length (Rule 5).

"We will start when he ___." will come / comes?

comes. No "will" in a time clause (Rule 8).

"This is the first time I ___ a tiger." see / have seen?

have seen. "The first time" takes the present perfect (Rule 4).

"Listen! Someone ___ the door." knocks / is knocking?

is knocking. "Listen!" = happening now (Rule 2).

Conditionals (1): The Four "If" Patterns

Error Pro bank, 70 questions · most tested: closed conditional (if + had + V3, would have + V3), no "will / would" in the if-clause, "If I were", mixed past-present sentences
How to read this rule book A conditional is a sentence with a condition (the if-clause) and a result (the main clause). The bank uses three names: open (= Type 1, real future), semi-closed (= Type 2, unreal now) and closed (= Type 3, unreal past). The Q column is the question number in the conditionals bank. Highlighted = the wrong part. Q ×N = bank questions on the rule. CGL+ = standard SSC rule not in this bank.

The four patterns at a glance

Trick: "If ke saath will / would kabhi nahi." The if-clause takes V1, V2 / were, or had + V3. "Will" and "would" live in the result clause only.

Rule 1 · Zero conditional: facts take present on both sides Q ×2

Rule: for a scientific fact or something that always happens, use the simple present in both clauses.

✗ If you mix red and yellow, you will have got orange. → ✓ If you mix red and yellow, you get orange.

Q✗ Wrong✓ Right

Rule 2 · Open conditional: If + V1, will + V1 Q ×7

Rule: for a real, possible future, the if-clause takes the simple present and the result takes will + V1 (passive: will be + V3). Never two "will"s, and not "will have been".

✗ If it will rain, we will stay in. → ✓ If it rains, we will stay in.

Rule 3 · Semi-closed: If + V2, would + V1 (unreal now) Q ×7

Conditionals (2): Wish, As If and the Subjunctive

Most tested: "demand / suggest / essential that" + base verb (15 questions), "I wish" + V2 or had + V3, "as if he were"
What is "mood"? Mood is the verb form that shows the speaker's attitude. A plain statement is the normal mood. The subjunctive is the form for wishes, orders, suggestions and imagined things: "I wish I were…", "I suggest that he go…". Hindi clue: when the meaning is "kare / ho / jaaye" (should do), not "karta hai", think subjunctive.

Wish and as if: one step back

Rule 11 · As if / as though + V2 (were) for an imagined comparison Q ×2

Rule: when the comparison is not true (he is not a billionaire), use "as if / as though + were / V2" for the present and "had + V3" for the past.

Rule 15 · Would rather / had better CGL+

Rule 16 · Lest … should + V1 CGL+

Rule: "lest" means "so that … not"; it takes "should + V1" (or the base verb) and never a "not".

✗ Walk carefully lest you will fall. ✗ …lest you should not fall. → ✓ Walk carefully lest you should fall.

Rule 17 · Provided that / in case / as long as + present, not "will" CGL+

Rule: these condition words act like "if": their clause takes the present for a future meaning.

✗ Take an umbrella in case it will rain. → ✓ …in case it rains. · ✓ You can go provided that you finish your work.
